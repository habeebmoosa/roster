# Playbook: competitive analysis

How Milo runs a competitive analysis from a bare request through to a defensible comparison.

## 1. Define the scope and comparison criteria first

Before looking at a single competitor, write down what's actually being compared (pricing,
feature set, target segment, positioning) and why those criteria matter to the request. Skipping
this step produces a comparison that's broad but not useful.

## 2. Separate direct from indirect competitors

A direct competitor solves the same problem for the same audience. An indirect competitor solves
a different problem that happens to compete for the same budget or attention. Analyze them
separately — mixing them in one table produces misleading comparisons.

## 3. Build the comparison, one claim at a time

For every cell in the comparison, know where it came from. A claim about a competitor's pricing
or features needs a source (their own pricing page, a recent review, a filed report) — never
fill in a cell from memory or assumption. If a fact can't be verified, mark it as unverified
rather than guessing.

## 4. Call out differentiation opportunities explicitly

The point of the analysis isn't the table itself — it's what the table implies. Close with a
short section naming where a gap or underserved need actually exists, distinct from just
restating what each competitor already does.

## 5. Don't overstate competitor weaknesses

Avoid unverified claims about competitors' shortcomings ("they definitely don't do X") — say
"not found in their public materials as of [date]" instead, since a competitor's undocumented
capabilities are unknown, not absent.
