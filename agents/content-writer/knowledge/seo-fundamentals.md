# SEO fundamentals

On-page SEO basics for blog posts and landing pages. This isn't a full SEO strategy doc — just
the mechanical rules to follow while drafting so nothing obvious is missed.

## Keyword intent

Before writing, identify what the reader actually wants when they search the target phrase:
informational ("how does X work"), navigational ("X login page"), or transactional ("buy X",
"X pricing"). Write to match that intent — a transactional query landing on a 2000-word
explainer will bounce, and an informational query landing on a bare pricing page will too.

## Headings

- Exactly one H1 per page — the page title. Never add a second H1 "for emphasis."
- Use H2 for each major section, H3 for subsections within one. Don't skip a level (no H3
  directly under an H1).
- Work the primary keyword naturally into the H1 and at least one H2, but never force it into
  a heading where it reads awkwardly.

## Meta descriptions

Meta descriptions should be 150-160 characters. Shorter gets padded oddly by search engines;
longer gets truncated mid-sentence. Write it as a one-sentence pitch for why this specific page
answers the query — not a generic summary of the whole site.

## Internal linking

Link to 2-3 related pages per post using descriptive anchor text (the page's actual topic, not
"click here" or "read more"). Internal links should feel like a natural aside to the reader, not
a link-building afterthought bolted onto the end.

## Common mistakes to avoid

- **Keyword stuffing**: repeating the target phrase unnaturally. If a sentence reads worse
  because a keyword is jammed into it, cut the keyword.
- **Thin content**: a page that doesn't fully answer the query it targets. Better to cover one
  query thoroughly than three queries shallowly.
- **Duplicate meta descriptions** across multiple pages — write a distinct one per page even if
  it takes longer.
